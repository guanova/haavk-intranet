## 0. 一句话定位

以 18 张截图视觉为基准，构建一个**零依赖、双击即开、离线可用**的"哈福克集团内网"单页应用：游客可浏览官网四个栏目（关于我们 / 员工论坛 / 解决方案 / 寻人启事），注册时需在《三角洲行动》世界观下选择"部门 → 职业/干员"（并支持自建新部门），登录后可维护个人资料、发帖、回复，全部数据落 `localStorage`。

### 1.3 双源验证与"存疑"处理规则（写入代码，不是写在文档里）

1. 每条数据带 `confidence` 字段；UI 渲染规则：
   - `confirmed`（截图直接可见）→ 正常显示；
   - `dual`（≥2 个独立公开来源一致）→ 正常显示，详情页显示来源；
   - `single`（仅 1 个来源）→ 选项后追加 `*`，选择器底部显示"标注项来源单一，可能有版本差异"；
   - `pending`（检索不到或来源冲突）→ 显示为灰色选项，后缀 `待确认`，并在选择器底部提供"自定义"入口。
2. 每个选择器（部门 / 职业 / 干员）**末尾固定追加** `+ 新建部门` / `+ 自定义职业` / `+ 手动输入干员名`，即使资料齐全也保留，用于兜底与用户扩写。
3. 自建部门：名称 trim + 去重（大小写/全半角/空格归一化后比对 `departments`），重复时给出明确错误；成功后写入 `departments`（`custom:true`），**立即可在本次及后续注册/资料编辑中被选择与复用**。

## 6. 状态管理方案

零依赖、单向数据流，手写 `store`（约 60 行）：

```
action ──▶ Store.dispatch(action) ──▶ reducer(state, action) ──▶ Persist(localStorage) ──▶ notify(subscribers)
                                                                          │
                                                          subscribe(fn) ──▶ 视图局部重渲染
```

| 模块 | 文件 | 职责 |
|---|---|---|
| `store.js` | 核心 | `getState / dispatch / subscribe`，浅比较后通知 |
| `persist.js` | 持久化 | 命名空间 `haavk.*`，`schemaVersion` 迁移，读写失败降级到内存 + 提示 |
| `session.js` | 会话 | 当前登录账号、`requireAuth()` 守卫 |
| `auth.js` | 认证 | 注册（唯一性、强度校验）、登录、改密、退出 |
| `db.js` | 领域服务 | 帖子 CRUD、回复、部门/职业/干员读取与自建去重、资料更新 |
| `router.js` | 路由 | hash 解析、参数、守卫、渲染后聚焦与滚动复位 |
| `views/*.js` | 视图 | 纯渲染函数 `render(ctx) => string` + `mount(root, ctx)` 事件绑定 |
| `components/*.js` | 通用件 | 无状态，返回 HTML 字符串 |

**持久化键位**：`haavk.schema` / `haavk.accounts` / `haavk.profile` / `haavk.departments` / `haavk.roles` / `haavk.operators` / `haavk.posts` / `haavk.replies` / `haavk.session` / `haavk.wanted` / `haavk.prefs`。

## 9. 技术选型（及理由）

| 选择 | 理由 | 备选与否决原因 |
|---|---|---|
| **原生 HTML + CSS + JS（ES2019，经典脚本）** | 交付物要求"双击即开、无后端、无构建"；经典 `<script>` 而非 ES Module，规避 `file://` 下 CORS 限制 | React/Vue 需构建或 CDN，离线不可靠；Vite 需 Node 环境 |
| **CSS 变量作为唯一设计令牌源** | 多页面风格不漂移，一处改全局生效 | Tailwind 需构建 |
| **Hash 路由 + 手写路由器** | 零依赖、`file://` 与 http 双通 | history API 在 `file://` 下刷新 404 |
| **localStorage 持久化 + 版本迁移** | 满足"刷新不丢数据"，无后端 | IndexedDB 复杂度过高（头像体积可控） |
| **图片资源全部内联 SVG 占位** | 避免版权风险，且零二进制资源 | 直接引用游戏原图会侵权 |
| **简易哈希 + 盐（非加密标准）** | 演示用；README 明确说明这是前端演示，非安全存储 | 明文存储更差 |
| **响应式策略** | 以 1280px 为设计画布，≥1280 居中留白；1024–1280 按比例压缩侧栏；<1024 侧栏折叠为抽屉、表格横向滚动 | 移动端完整适配不在本期范围（截图为 PC 活动页） |

## 12. 已知风险与兜底

| 风险 | 兜底 |
|---|---|
| 检索不到某些部门/干员官方名 | 该选项标"待确认"，并在选择器底部保留"自定义"入口 |
| 图片资源无法提供 | 全部占位 SVG，README 列出替换清单与建议尺寸 |
| `file://` 下 localStorage 受限（部分浏览器策略） | 捕获异常 → 降级内存存储 + 顶部黄条提示"当前环境无法持久化，请用本地服务器打开"（提供 `serve.cmd`） |
| 中文字体差异导致标题观感偏差 | 令牌集中定义字体栈，README 说明可替换为本地字体文件 |
| 截图小字识别存在不确定性 | 所有从截图提取的文案在 `docs/02` 中逐条标注"截图直读"，与检索结论区分开 |
