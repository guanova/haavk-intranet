## 2. 颜色令牌（CSS 变量）

```css
:root{
  /* —— 基础色：浅色区 —— */
  --c-bg-light:      #F0F0F0;  /* 顶部导航/主视觉底色 */
  --c-bg-light-2:    #E4E6E9;  /* 卡片底、次级面 */
  --c-panel:         #e9edf4;  /* 侧栏卡片面（实为 #e6ebf3→#edf0f6 竖向渐变） */
  --c-line-soft:     #D8DCE1;  /* 分隔线 */
  --c-line:          #C3C7CC;  /* 列表行底线 */

  /* —— 基础色：深色区 —— */
  --c-bg-dark:       #1F1F1F;  /* 优秀员工带 / 首页页脚状态栏（照片采样） */
  --c-bg-dark-2:     #2B2929;  /* 深色卡片 */

  /* —— 品牌与强调 —— */
  --c-brand:         #1E9BF0;  /* 主蓝：导航选中、按钮、轮播高亮、卡片蓝底 #1687E8~#1E9BF0 */
  --c-brand-deep:    #0E7CD4;
  --c-brand-soft:    rgba(30,155,240,.14);
  --c-accent-red:    #C62828;  /* 警示、必填标记（书签红条已于 2026-10-24 按用户指令移除） */
  --c-accent-red-2:  #E8453C;

  /* —— 文字 —— */
  --c-text-strong:   #111111;  /* 大标题 */
  --c-text:          #1F1F1F;  /* 正文 */
  --c-text-sub:      #555555;  /* 副标题/释义 */
  --c-text-mute:     #7A7A7A;  /* 表格表头、时间戳 */
  --c-text-on-dark:  #FFFFFF;
  --c-text-on-dark-sub: #9A9A9A;

  /* —— 状态 —— */
  --c-disabled-bg:   #9E9E9E;  /* "发帖"灰条、"已售罄"按钮 */
  --c-danger:        #D93025;

  /* —— 论坛列表专用 —— */
  --c-row-alt:       #F4F6F8;  /* 论坛行间纹（浅蓝灰） */
  --c-row-hover:     #E9F3FD;
  --c-head-bar:      #3A3A3A;  /* [已弃用] 旧论坛表头深灰条——像素考据订正：表头实为浅底深字+蓝下划线，见 §5.4 */

  /* —— 轮播指示器 —— */
  --c-dot-idle:      rgba(120,120,120,.5);  /* 空心方块描边 */
  --c-dot-active:    #29A9F5;               /* 实心方块 */

  /* —— 商城/寻人启事 —— */
  --c-coin:          #E6E6E6;  /* 哈夫克币图标与数字 */
  --c-soldout:       rgba(60,60,60,.55);
}
```

**色彩使用规则（关键，决定还原度）**

1. 一个页面**只能有一处大面积品牌蓝**：要么是主视觉斜切块，要么是卡片蓝底，二者不同屏竞争。
2. 品牌蓝只出现在四处：① L2 导航当前项；② 轮播当前指示块；③ 主按钮/高亮底；④ 优秀员工卡蓝底。
3. 红色**仅**作为左侧书签条 + 极小面积强调，绝不用于大面积、绝不用于按钮常态。
4. 深色区与浅色区**硬切**，不使用渐变过渡。

## 5. 组件样式基准

### 5.1 顶部导航
- L1 条：高 44px（--nav-h-l1），「◀ 活动」22px/700，chevron 与文字间有 1×10px 浅灰分隔线（#c9cdd4），右侧细纹装饰条。
- L2 条：高 56px，左端 HAAVK 六边形折线标（内联 SVG，宽 66×22），中部主导航项 16px，间距 ≈96px，当前项 `--c-brand` + 字重 600，其余 `--c-text-strong`。
- 右端「◀ 三角图标 · 注意力点数 | 2019」：数字用 `--font-num`，前缀小三角为菱形/三角几何图标。
- 导航底边 1px `--c-line-soft`。

### 5.2 左侧书签条（截图特有）——**已按用户指令删除（2026-10-24）**
> 用户指令："把那行红色的线删掉"。参考图中的红色翻页书签条（含首页深色带内的同款、以及各子页左下固定条）已从实现中整体移除，不再复现。以下为历史考据存档。
>
> 位置固定在内容区最左 `x≈60–76`，宽 16px，自 `y≈290` 延伸至页脚；红色实条（`--c-accent-red`）＋深色半透明横幅内白色 `›` 与竖排小字；随滚动进度变化。曾实现为 `.bookmark`（fixed 烘焙图）与首页 `.band-pager`，均已删除。

### 5.3 侧栏信息卡（像素验收值 2026-10-20）
无描边、底色轻微竖向渐变 `linear-gradient(180deg,#e6ebf3,#edf0f6)`（照片采样 220→235）；横向内边距 7px（发帖按钮 236px 宽反推），头部 padding-top 14px、body padding-top 5px；
标题行：16px/900 ＋ 同行右侧英文水印（11px、宽字距 .36em、浅灰影 `#d8dce4`）；标题下划线 = **68px 深色 1px 短线 `#1e2730` ＋ 中灰 1px 延长线 `#9198a2`**（订正：非 2px 黑粗线）。
公告/说明文字直接压卡底（**无灰色底框**，订正 v1 错误）：15px/22px、`#2f353c`；论坛公告版心 x81-321（16 字/行），两段间距 31px。
条目块：图标＋标题 14px/700 ＋ 释义 13px（行距 ≈19px）；解决方案条目无硬分隔线、节距 ≈37px（89-90px/条）；论坛舆情条目间有 1px 浅线。
底部操作按钮（「发帖」）：236×38，灰底 `--c-disabled-bg`，白字（禁用态）。

### 5.4 论坛表格
- 表头：**浅底（白/浅灰）＋ 深色粗体小字，宽字距；底部通宽 3px 品牌蓝下划线 `--c-brand`**（像素考据订正：参考照片表头并非深灰条——照片白≈#D0DCEA 偏色下表头底为 #CAD5E9、文字近黑 #16232C、下划线核心 #376DAB–#396BB4 即去饱和后的品牌蓝）；列宽 标题自适应 / 发帖人 190 / 回复 80 / 最后回复 130。
- 行高 80px（置顶行 92px，大图标 ⤒ 24×30 钢蓝、无复选框），平铺无斑马纹，行间 1px `#6e7e97`；hover `--c-row-hover`。
- 「置顶」行标题 700。
- 未读/已读复选框：14×14，1px `--c-text-mute` 描边方形，选中后蓝底白勾。
- 发帖人单元格：48×48 方形头像（无圆角）＋ 昵称 14px/700 ＋ 部门 12px/`--c-text-mute`。
- 底部条形栏：左侧「▲ 系统置顶」，右侧三项复选筛选「全新未读 / 有未读回复 / 全部已读」，选中项前有 `--c-brand` 实心方块。
- **滚动指示条**：侧栏卡右缘内侧（参考 x327-331）一条 4px 钢蓝竖条 `#7e9ac5`；仅出现在有滚动列表的页（论坛/解决方案），静态页（首页/寻人启事）没有。实现为 `.scroll-thumb`（`position:fixed; left:calc(50% - 312px); top:33vh`）：论坛高 46.5vh（约 33%→79% 视口），解决方案 `.scroll-thumb--long` 高 59.3vh（33%→92%）。解决方案商品列表右缘另有 3px 短竖线 `#7896c6`（x1194-1196、从列表顶开始 132px，在卡外 9px 空隙上，实现为 `.sol-rail`）。全站隐藏原生滚动条。

### 5.5 按钮体系
| 类型 | 常态 | hover | active | disabled |
|---|---|---|---|---|
| 主按钮 | `--c-brand` 底、白字、0 圆角、高 44 | 提亮至 `#3FB0FF` | `#0E7CD4` | `--c-disabled-bg`、`cursor:not-allowed` |

### 5.6 输入框
高 44px，白底，1px `--c-line` 描边，**0 圆角**，内边距 0 14px，字号 14。
focus：描边 1px `--c-brand` ＋ `box-shadow:0 0 0 3px var(--c-brand-soft)`。
error：描边 `--c-accent-red-2`，下方 12px 红字提示。
disabled：`--c-bg-light-2` 底 + `--c-text-mute` 字。
placeholder：`--c-text-mute`。
