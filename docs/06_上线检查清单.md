## 必做（安全与合规）

1. **修改管理员初始密码**
   - 账号 `webops_admin` 的初始密码写在 `server/lib/seed.js`（`Haavk@Admin2026`）。
   - 上线后第一时间：登录 → 个人资料 → 修改密码；或直接在库里重置后重启。
   - 同时检查 `server/lib/seed.js` 里的初始密码是否需要改成更长的随机串再首次启动。

2. **填写真实备案信息**
   - 管理面板 → 站点配置 → `filing.*`（ICP 备案号 / 公安备案号 / 主办单位 / 版权声明）。
   - 全部留空时页脚整条不渲染（现状即如此）；填写后自动出现在页脚。
   - 未备案的境内服务器不得提供公开访问，先备案再上线。

3. **决定演示数据去留**
   - 当前库内含演示内容：15 个演示员工（统一密码 `Haavk#2026`）、24 帖、64 回复、4 位 AI 高管发言。
   - 演示员工密码公开在文档里，**上线前必须清理或改密**。
   - 清理方式：`node server/tools/reset.js --yes`（清空业务数据）→ 重启自动重建基础数据；AI 高管保留（角色账号非演示数据）。

## 建议（内容运营）

4. **AI 高管发言**
   - 现状：素材池驱动（每位 6–8 条发言 + 10 条发帖选题），间隔 30/45/60 分钟随机轮转。
   - 若要更拟真：接入大模型生成，只需替换 `server/workers/index.js` 三处取文案的调用（素材池函数签名不变）。
   - 素材池可直接在管理面板 → AI 高管配置里编辑，无需改代码。

5. **点数规则的运营口径**
   - 现规则：每日领取 500 / 发帖 -50 / 回复 -20（回复已降价鼓励讨论）。
   - 管理面板 → 站点配置可实时调整；若做运营活动（如双倍领取日），改 `points.daily_amount` 即可。
   - 建议观察首周数据再调：`points_ledger` 表有完整流水，可用对账脚本 `node server/tools/reconcile.js` 校验。

6. **新用户冷启动**
   - 注册后需「办理入职手续」经管理员审批才能发帖——这是角色扮演的核心机制，但对大众用户是门槛。
   - 建议：上线初期管理员高频处理审批（管理面板 → 入职审批）；若审批压力太大，可考虑把某部门设为"自动通过"（需小改 `server/api/admin.js` 审批逻辑，另立项）。

7. **版权与素材**
   - 页面人物/装备图片来自游戏官方公开素材（清单见 `docs/05_素材候选清单.md`，CC BY-NC-SA 4.0），**仅限非商业演示**。
   - 商业上线前必须替换为自有或已授权素材；参考截图裁切件同理。
